# Стратег

ИИ-агент для руководителя цифрового продукта. Он берёт размытый вопрос вроде «почему падает удержание» или «кому продавать новый сервис», проводит исследование по открытым источникам и материалам руководителя, предлагает несколько разных вариантов с сильными возражениями и собирает согласованные продуктовую и коммуникационную стратегии с планом проверки. Если задача пришла брифом с заданной формой сдачи, агент сдаёт документ ровно в этой форме и считает экономику в финансовой модели. После решения агент хранит его основания, напоминает об обязательствах и пересматривает выводы, когда приходят новые данные.

Готовые результаты можно посмотреть без установки. Отчёты открываются прямо в браузере:

- [Связь для близких и собственных устройств](https://anazarovskiy.github.io/strateg/projects/svyaz-dlya-blizkih-i-sobstvennyh-ustroys/report.html)
- [Кому продавать ИИ-секретаря и пересмотр после новостей](https://anazarovskiy.github.io/strateg/projects/ii-pomoschnik-dlya-zvonkov-s-neznakomyh/report.html)
- [Диагностика падения удержания](https://anazarovskiy.github.io/strateg/projects/padenie-uderzhaniya-novyh-polzovateley-p/report.html)

Папки проектов:

- `projects/svyaz-dlya-blizkih-i-sobstvennyh-ustroys/` — демонстрационный бриф «Связь для близких и собственных устройств»: документ из пяти частей ровно по брифу, финансовая модель, где каждое допущение и каждый результат — запись реестра, план по кварталам, ресурсы и риски. 18 минут, $4,52, два решения человека.
- `projects/ii-pomoschnik-dlya-zvonkov-s-neznakomyh/` — кому продавать ИИ-секретаря: исследование по 36 открытым источникам и пересмотр после новостей руководителя (раздел «Пересмотры»).
- `projects/padenie-uderzhaniya-novyh-polzovateley-p/` — диагностика падения удержания по таблице когорт.

Сравнение с обычным чатом на тех же задачах, включая случаи, где чат выиграл, — в `evals/results.md`. Описание работы — `docs/strateg-opisanie.pdf`.

Это не отдельная программа, а папка: инструкции, методики, навыки, субагенты, хуки и небольшой инструмент командной строки `strat` на Python. Открываете её в Claude Code (или в Cursor и других средах, см. ниже) и ставите задачу обычным текстом.

Главная идея — реестр утверждений. Каждое существенное утверждение в документах проекта ссылается на запись вида `[C-012]`. У записи есть тип (факт, наблюдение, оценка, прогноз, гипотеза, допущение, вывод, синтетический ответ), источник со снимком текста и дословная цитата. `strat` не примет цитату, которой нет в источнике, а проверка документов не даст выдать гипотезу или ответ модельного респондента за факт. На этом же реестре держатся продолжение работы после перерыва, память, которая не превращает старый вывод в факт, и пересмотр: при новых данных агент находит все выводы и решения, которые стояли на изменившейся записи.

## Быстрый старт

Что нужно:
- Claude Code с подпиской Claude Pro или Max либо с ключом API ([установка](https://code.claude.com/docs/en/setup.md));
- Python 3.9 или новее (на macOS обычно уже есть; иначе `xcode-select --install` или `brew install python`);
- git — по желанию.

Платных сервисов, кроме самой модели, нет. Сторонние Python-пакеты не нужны. Ключи API в репозиторий класть не нужно и нельзя.

```bash
# 1. Установить Claude Code (macOS, Linux)
curl -fsSL https://claude.ai/install.sh | bash

# 2. Открыть папку агента
git clone <ссылка на репозиторий> strateg && cd strateg
./strat doctor          # проверка окружения: Python, необязательные утилиты, права на запись

# 3. Запустить Claude Code в этой папке
claude
```

При первом запуске Claude Code спросит, доверяете ли вы папке (нужно, чтобы заработали хуки и разрешения из `.claude/settings.json`), и предложит включить MCP-сервер `strat` из `.mcp.json`. Согласитесь на оба.

Дальше задача ставится одной командой:

```
/strateg Почему с апреля падает удержание новых пользователей нашего приложения? Выгрузка во вложении.
```

Агент заведёт проект в `projects/<имя>/`, задаст пару уточняющих вопросов и пойдёт по этапам. Внизу экрана строка статуса показывает проект, этап, число источников и записей, вопросы, которые ждут вашего решения, и стоимость.

На Windows: нужен Git for Windows (Claude Code использует Git Bash) и Python, доступный как `python3`. Вместо `./strat` можно писать `python tools/strat.py`.

## Как с ним работать

| Нужно | Что делать |
|---|---|
| Остановить | `Esc` в Claude Code. Состояние уже в файлах проекта |
| Уточнить задачу | написать в чат; агент обновит `brief.md` и при необходимости план |
| Исправить результат | править markdown-файлы проекта напрямую или попросить агента; после правки `./strat lint` покажет, не сломались ли ссылки |
| Продолжить после перерыва | открыть новый чат в этой папке и написать «продолжи» или `/strateg-resume`; хук сам подгрузит сводку |
| Посмотреть, что сделано | `./strat status`, `./strat log`, `./strat cost` |
| Получить отчёт | `projects/<имя>/report.html` (собирается командой `./strat report`) |
| Добавить новые данные | приложить файл и написать, что изменилось, или `/revisit` |
| Вычитать отчёт перед отправкой | `./strat consistency` покажет, где срок теста или порог эффекта в разных разделах записан по-разному |
| Проверить решения | `./strat decision check`: сроки пересмотра, просроченные обязательства, устаревшие основания |

## Как устроено

```
AGENTS.md, CLAUDE.md      постоянные правила агента (AGENTS.md читают и другие среды)
.claude/skills/           15 навыков: процедуры этапов (frame, research, options, product, comms, ...)
.claude/agents/           4 субагента: researcher, extractor, critic, respondent
.claude/settings.json     хуки, строка статуса, разрешения
knowledge/                методики: доказательность, JTBD, варианты, эксперименты, интервью, UX, данные
templates/                шаблоны документов проекта
tools/strat.py, ./strat   CLI: реестры, проверки, состояние, анализ влияния, поиск, стоимость, отчёт, MCP
config/                   политика источников и тарифы моделей
projects/<имя>/           всё по конкретной задаче: материалы, снимки, реестр, документы, состояние, журнал
evals/                    протокол сравнения с обычным чатом и тестовые задачи
tests/                    автотесты инструментов
docs/                     архитектура, модели и инструменты, возможности, ограничения, сценарий демо
```

Постоянные инструкции, методики, материалы проекта и состояние задачи хранятся раздельно: правила в `AGENTS.md` и навыках, методики в `knowledge/`, материалы и снимки в `projects/<имя>/sources/`, состояние в `projects/<имя>/state.json`, действия и стоимость в `projects/<имя>/log/`.

Процесс: постановка → материалы → исследование → варианты → стратегия → отчёт → решение → сопровождение. Каждый этап закрывается только после того, как `./strat lint` не находит ошибок в его документах. Человек подключается в четырёх точках: рамка задачи, дорогое исследование, выбор варианта, фиксация решения.

Пример прогона на тестовой задаче с открытыми данными: [examples/README.md](examples/README.md), отчёт — `projects/example-call-assistant/report.html`.

Подробно: [архитектура](docs/architecture.md), [модели и инструменты](docs/models-and-tools.md), [что реализовано из дополнительного уровня](docs/capabilities.md), [ограничения](docs/limitations.md), [сценарий демонстрации](docs/demo-script.md).

## Модели и стоимость

Основная сессия работает на модели, которую вы выбрали в Claude Code (для стратегии разумно взять Opus 5.5, для экономии — Sonnet 5.5). Субагенты закреплены за моделями по задаче: извлечение утверждений из документов — Haiku 5.5, поиск по вопросу плана — Sonnet 5.5, независимая критика — Opus 5.5, модельные респонденты — Sonnet 5.5.

Стоимость считается автоматически: хук после каждого ответа читает журнал сессии Claude Code, складывает токены основной сессии и субагентов и умножает на тарифы из `config/prices.json`. `./strat cost` показывает разбивку по этапам и моделям. При подписке Pro или Max токены отдельно не оплачиваются, тогда цифра показывает эквивалент по тарифам API.

## Данные и безопасность

- Только открытые источники и материалы руководителя. Хук проверяет каждый адрес по `config/policy.json`: корпоративные вики и трекеры, страницы входа, внутренние адреса запрещены.
- Текст источников считается данными. Если в странице или файле есть указания для ИИ, `strat` помечает источник, хук сообщает агенту, а агент показывает это руководителю, но не выполняет.
- Секреты не попадают в файлы: хук не даст записать текст, похожий на ключ или пароль.
- Расшифровки интервью регистрируются только обезличенными (`--redact` убирает телефоны, почту, номера документов).
- Реестры, снимки источников, состояние и журналы меняются только через `strat`: хук блокирует ручную правку, чтобы доказательная база оставалась честной.

## Проверка

```bash
python3 -m unittest discover -s tests -v   # 16 тестов: реестр, сверка цитат и чисел, проверки, хуки, MCP, стоимость, отчёт
./strat doctor
```

## Другие среды

`AGENTS.md` читают Cursor, Codex, GitHub Copilot и другие агенты. Для Cursor есть `.cursor/rules/strateg.mdc` и `.cursor/mcp.json`: правила те же, процедуры навыков агент читает из `.claude/skills/`, инструменты доступны через MCP-сервер `strat`. Хуков там нет, поэтому то, что в Claude Code делают хуки (сводка при старте, проверка перед концом хода), описано в правилах как обязательные шаги. Проект, начатый в одной среде, продолжается в другой: всё состояние лежит в `projects/<имя>/`.
