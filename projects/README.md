# Проекты

Каждая задача руководителя продукта — отдельная папка. Создаётся командой `./strat init "Название задачи"` или навыком `/strateg`. Активный проект записан в `projects/.active`.

Структура проекта: `brief.md` (постановка), `inputs/` (материалы руководителя), `sources/` (реестр и снимки источников), `evidence/claims.jsonl` (реестр утверждений), `research/`, `options.md`, `strategy/`, `summary.md`, `decisions/`, `revisions.md`, `analysis/` (скрипты и расчёты), `interviews/`, `log/` (журнал и стоимость), `state.json` (состояние процесса), `report.html` (итоговый отчёт).
