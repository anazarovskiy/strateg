SpeechKit, правила тарификации (aistudio.yandex.ru/docs/ru/speechkit/pricing; ранее yandex.cloud/ru/docs/speechkit/pricing). Даты обновления на странице нет; извлечено 2026-11-16 через WebFetch.
Единица тарификации — отрезок одноканального аудио длительностью 15 секунд. (синхронное распознавание)
Стоимость использования SpeechKit в режиме потокового распознавания рассчитывается по правилам тарификации синхронного распознавания.
Цены в рублях, НДС включен, за 15 секунд аудио:
Потоковое распознавание | 0,1626 ₽
Асинхронное распознавание файлов* | 0,1515 ₽
Асинхронное распознавание файлов, отложенный режим* | 0,0381 ₽
* Посекундная тарификация с 16 секунды.
Синтез речи. Стоимость использования SpeechKit для синтеза речи зависит от версии используемого API.
Синтез с использованием API v1, за 1 млн символов | 1 342 ₽
Синтез с использованием модели general в API v3, за запрос | 0,1626 ₽
Синтез с использованием модели livetts в API v3, за запрос | 0,25 ₽
Синтез с использованием модели Speech TTS Live в Realtime API, за один начатый блок из 250 символов | 0,25 ₽
Все цены в рублях и тенге указаны с НДС, все цены в долларах — без НДС.
