# Отчёт

1. `./strat stage report start` — появится шаблон `summary.md`.
2. `summary.md`: ответ на вопрос из `brief.md` в 2–3 предложениях; рекомендация; 3–5 главных оснований со ссылками; чего не знаем и чем рискуем; что решить сейчас (конкретные шаги и роли).
3. Перечитай документы глазами руководителя: понятно ли без пояснений, нет ли расхождений между `product.md` и `comms.md`, у всех ли чисел есть период и ссылка.
4. `./strat lint --stage report`, исправь ошибки, затем `./strat report`.
5. Дай руководителю путь к `report.html` и короткое резюме в чате (5–8 строк), стоимость по `./strat cost` и список решений, которые за ним.
6. После его правок обнови документы, снова `./strat report`, затем `./strat stage report done`.
