# Анализ данных

## Проверка до расчётов

`./strat data profile <файл>` находит часть проблем автоматически. Остальное проверяй сам:

| Что проверить | Как выглядит проблема |
|---|---|
| Единицы | в одном столбце проценты и доли (35% и 0,31), рубли и тысячи рублей, с НДС и без |
| Периоды | пропущенные месяцы, неполный последний период, разная длина периодов |
| Определения | «активный пользователь» за день или за месяц; выручка начисленная или полученная |
| Пропуски | пустые значения означают ноль или «нет данных»? |
| Дубликаты | одна строка выгружена дважды, пересекающиеся периоды |
| Выбросы | ошибка ввода или реальное событие (акция, сбой)? |
| Изменения учёта | новое событие в аналитике, смена фильтров, миграция системы |
| Часовые пояса | суточные данные «съезжают» на соседний день |

Найденное фиксируй в `analysis/profile_<имя>.md` и учитывай в выводах.

## Выбор метода

| Вопрос | Метод |
|---|---|
| Из чего складывается изменение | разложение на сегменты, смена состава против изменения внутри групп (`diagnostics.md`) |
| Удержание и отток | когортные кривые по периоду привлечения |
| Где теряем людей | воронка по шагам с конверсией каждого шага |
| Есть ли разница между группами | разница долей с доверительным интервалом; для малых групп — осторожно |
| Сезонность | сравнение с тем же периодом прошлого года, недельные циклы |
| Экономика | юнит-экономика в трёх сценариях (`product-strategy.md`) |

Парадокс Симпсона: общая тенденция может быть противоположна тенденции в каждой группе. Всегда смотри разрезы.

## Разница долей: быстрая проверка

Для долей p₁ и p₂ в группах размером n₁ и n₂ стандартная ошибка разницы ≈ √(p₁(1−p₁)/n₁ + p₂(1−p₂)/n₂). Если разница меньше двух стандартных ошибок, называть её значимой нельзя.

## Воспроизводимость

- Расчёт живёт в скрипте `analysis/<имя>.py`, который читает исходный файл проекта и пишет результат в `analysis/<имя>.md`.
- В результате указываются входной источник (S-…), дата расчёта и ключевые допущения.
- Результат регистрируется как источник (`--kind analysis`), а числа из него — записями `estimate` с `--method`.

## Как писать о числах

Число, единица, период, сравнение, ссылка: «D30 новых пользователей Android — 22% в апреле против 31% в январе 2026 [C-002, C-003]». Округляй до точности данных. Не пиши «значительно», если не проверял значимость.
