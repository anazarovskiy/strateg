# Методическая база

Файлы не зависят от проекта. Навыки ссылаются на них в нужный момент, поэтому целиком их заранее читать не нужно.

| Файл | Когда читать |
|---|---|
| `evidence.md` | типы утверждений, шкала надёжности источников, цитаты, независимость источников, пробелы |
| `framing.md` | постановка задачи и вопросы, которые меняют решение |
| `research.md` | план исследования, тактика поиска, открытые источники по российскому рынку |
| `jtbd.md` | аудитория через ситуацию и задачу, альтернативы, силы перехода |
| `diagnostics.md` | метрика упала или выросла: как найти причину |
| `data-analysis.md` | проверка данных и выбор метода расчёта |
| `interviews.md` | гайд, реальные интервью, модельные респонденты и их границы |
| `ux-review.md` | разбор интерфейсов и пользовательских путей |
| `options.md` | как строить разные варианты, «что должно быть правдой», pre-mortem |
| `product-strategy.md` | каркас продуктовой стратегии и экономика |
| `comms-strategy.md` | барьер, сообщение, подтверждение, каналы, аудит обещаний, закон о рекламе |
| `experiments.md` | план проверки: сравнение, размер выборки, срок, ограничительные метрики |
| `unit-economics.md` | эффект к базе «без изменений», воронка, сверка остатков, прибыль, безубыточность, сценарии, окупаемость |
| `style.md` | как писать документы для руководителя |
