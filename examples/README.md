# Пример: прогон на тестовой задаче

Пока бриф демонстрационного проекта не опубликован, агент проверен на задаче 01 из `evals/tasks/`: ИИ-помощник, который отвечает на звонки с незнакомых номеров, — кому продавать платную версию и что сказать аудитории. Только открытые данные.

Проект лежит в `projects/example-call-assistant/`. Главное:

- `report.html` — итоговый отчёт с метками типов утверждений, реестром, источниками и разделом «Как получен результат»;
- `summary.md` — короткий ответ;
- `research/findings.md`, `options.md`, `strategy/*.md` — документы этапов;
- `decisions/D-001.md` и `revisions.md` — решение и пример пересмотра при новых данных;
- `analysis/economics.py` — воспроизводимый расчёт экономики.

Посмотреть состояние: `./strat use example-call-assistant && ./strat status`.

## Что в этом прогоне по-другому, чем в Claude Code

Пример собран в облачной песочнице с теми же инструментами `strat`, но без самого Claude Code. Из-за этого:

- прямой доступ к сайтам из Python был закрыт, поэтому страницы читались через WebFetch и регистрировались командой `source note` с пометкой «дословность не гарантирована». Цитаты из таких источников не сверяются автоматически (в отчёте — «не проверялась»). На вашем компьютере `./strat source fetch` сохраняет дословные снимки, и сверка работает для всех источников;
- хуки не работали: журнал вызовов инструментов и стоимость не записывались, а длительность этапов в отчёте отражает время сборки примера, а не работы агента;
- субагенты не запускались: возражения к вариантам написаны в основной сессии (в Claude Code их пишет `critic`), исследование шло последовательно;
- ответы руководителя (H-001, H-002) смоделированы автором теста и так помечены в документах.

## Что показал прогон

- Проверка документов поймала настоящую ошибку: в разделе «Факты» варианта 3 пункт опирался только на вывод агента. Этап не закрылся, пока к выводу не добавили исходные факты.
- Предупреждения о старых данных сработали: цена конкурента взята по данным мая 2025 года, запись устарела, и это видно в документах, в решении (`./strat decision check`) и в обязательстве K-004 перепроверить цену.
- Противоречие между блогом и заголовком издания о том, чья подписка «Секретарь+», оформлено как пересмотр R-001: `./strat impact` нашёл два затронутых места, рекомендация не изменилась.
