## Особенности работы в Claude Code

- При старте сессии хук присылает сводку проекта (этап, незавершённые шаги, вопросы руководителю, сроки решений). Начинай с неё. Команда `/strateg-resume` делает то же явно.
- Навыки из `.claude/skills/` подгружаются по описанию; руководитель может вызвать их сам: `/strateg <задача>`, `/frame`, `/research`, `/options`, `/report`, `/revisit` и другие.
- Субагенты из `.claude/agents/`: `researcher`, `extractor`, `critic`, `respondent`. Независимые вопросы плана исследования отдавай нескольким `researcher` параллельно, по одному вопросу на субагента.
- Вопросы руководителю задавай через AskUserQuestion с вариантами, ответ фиксируй командой `./strat answer H-…`.
- Прогресс показывай списком задач Claude Code: этапы процесса и шаги текущего этапа.
- Хуки ведут журнал инструментов и стоимость, не пускают к запрещённым адресам и не дают править реестры в обход `./strat`, а перед концом хода проверяют ссылки в изменённых документах. Если хук остановил ход из-за ошибок проверки, исправь их; обходить проверку нельзя.
- Если в цитате есть кавычки или апострофы, удобнее MCP-инструмент `strat_claim_add` (сервер `strat` из `.mcp.json`): не нужно экранирование в оболочке.
- Команды оболочки запускай по одной и из корня папки агента: без `cd`, без склейки через `&&` и `;` с `mkdir`, `cat` или heredoc. Склеенная команда с `cd` всегда требует ручного подтверждения и останавливает работу. Файлы читай инструментом Read, документы создавай Write, папки шаблонов создаёт `./strat stage … start`.
