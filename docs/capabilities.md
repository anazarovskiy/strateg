# Что реализовано

## Обязательный минимум

| Требование | Как сделано | Где посмотреть |
|---|---|---|
| Поставить задачу | навык `frame`: вопрос, решение, получатель, ограничения, данные; не больше 3–4 вопросов с вариантами; вопросы, меняющие решение | `.claude/skills/frame`, `templates/brief.md` |
| Собрать материалы | документы, таблицы, PDF, страницы, изображения, видео, расшифровки → реестр источников со снимком и хэшем | `./strat source add|fetch|note` |
| Провести исследование | план от вопросов, меняющих решение; параллельные `researcher`; сопоставление источников; раздел «Чего мы не знаем» обязателен | навык `research`, `templates/findings.md` |
| Предложить варианты | не меньше трёх, статус-кво обязателен, «закрыть» — по умолчанию; факты, гипотезы и прогнозы раздельно; возражения от `critic` | навык `options`, проверки E202–E206 |
| Разработать стратегию | продуктовая, коммуникационная с аудитом обещаний, план проверки | навыки `product`, `comms`, `validation` |
| Рабочий процесс | этапы с проверкой на выходе, четыре точки участия человека | `./strat stage`, навык `strateg` |
| Порядок в знаниях | четыре слоя хранятся раздельно | `docs/architecture.md` |
| Продолжение после перерыва | `state.json`, сводка хуком при старте, идемпотентные шаги | `/strateg-resume`, `./strat status` |
| Прозрачность | журнал действий, реестр с цитатами, стоимость по этапам, приложение «Как получен результат» | `./strat log`, `./strat cost`, `report.html` |

## Дополнительный уровень

| Возможность | Статус | Как работает | Как проверить |
|---|---|---|---|
| Интервью и модельные респонденты | есть | гайд по принципам интервью о прошлом поведении; разбор реальных расшифровок с обезличиванием; субагент `respondent` без доступа к файлам; синтетика — отдельный тип записей, проверка не пускает её в факты | навык `interview`; тест `test_02_synthetic_rules` |
| Изображения, аудио, видео | частично | изображения и PDF — через Read с привязкой наблюдений к экрану; видео — кадры через ffmpeg; аудио — через whisper, если установлен, иначе готовая расшифровка | `./strat media frames`, `./strat doctor` |
| Анализ пользовательского опыта | есть | путь пользователя, эвристики Нильсена, шкала серьёзности, наблюдения отдельно от интерпретаций | навык `ux`, `knowledge/ux-review.md` |
| Анализ данных | есть | профиль таблицы (единицы, пропуски, пропущенные недели и месяцы, выбросы), расчёты только скриптами, результаты как оценки с методом; синтетический датасет с известными причинами для проверки | `./strat data profile`, `evals/tasks/03-retention-data.md` |
| Поддержка решений | есть | решение с основаниями, ответственным, показателями, датой и условиями пересмотра; обязательства со сроками; сводка «решить сейчас» в начале каждой сессии | `./strat decision add|check`, `./strat commit add` |
| Пересмотр при новых данных | есть | статусы записей, анализ влияния по графу связей, журнал пересмотров; решения с изменившимися основаниями выходят в сводку | `./strat impact`, навык `revisit` |
| Маршрутизация | есть | выбор процесса с записью причины, модели субагентов по задаче и цене, запасные пути инструментов, правило повторного извлечения при плохой сверке цитат | `AGENTS.md` раздел «Маршрутизация», `./strat log --kind route` |
| Навыки, хуки, субагенты | есть | 15 навыков, 6 хуков и строка статуса, 4 субагента; у каждого компонента записано, зачем он нужен | `docs/architecture.md` |
| Интеграции через MCP и CLI | есть | `strat` как CLI и как MCP-сервер с 21 инструментом | `.mcp.json`, `.cursor/mcp.json`, тест `test_11_mcp` |
| База знаний | есть | методики в `knowledge/`; поиск по формулировке со стеммингом и по связям; смысловой поиск — переформулировки запроса моделью; память, которая не превращает выводы в факты; исправление и отзыв записей с историей | `./strat search`, `./strat claim update|retract|supersede` |
| Устойчивость к сбоям | есть | журнал сбоев, один повтор и запасной путь, атомарная запись и блокировки, идемпотентные шаги, хуки не роняют работу | `./strat step`, `log/hook_errors.log` |
| Переносимость | есть | всё состояние в файлах; `AGENTS.md`, правила и MCP для Cursor | `.cursor/`, `docs/architecture.md` |
| Сравнение с исходным способом | протокол готов, замеров нет | три тестовые задачи, рубрика, автоматическая проверка структуры ответа, таблица результатов | `evals/`, `./strat eval <файл.md>` |
