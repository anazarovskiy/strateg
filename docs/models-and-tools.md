# Модели, сервисы и инструменты

## Модели

| Модель | Где используется | Зачем именно она | Цена, $ за 1 млн токенов (вход / выход) |
|---|---|---|---|
| Claude Opus 5.5 | основная сессия (рекомендуется); субагент `critic` | синтез, варианты и стратегия — главная ценность результата; критике нужна сильная модель | 4 / 20 |
| Claude Sonnet 5.5 | основная сессия в экономном режиме; `researcher`, `respondent` | поиск и чтение источников, ролевые ответы: хорошее качество при цене вдвое ниже Opus | 2 / 10 |
| Claude Haiku 5.5 | `extractor` | механическое извлечение утверждений из документов; ошибки ловит сверка цитат | 0,10 / 0,50 (до 100 тыс. токенов в запросе) |

Цены — по [странице тарифов](https://platform.claude.com/docs/en/about-claude/pricing), проверены 09.11.2026 и записаны в `config/prices.json` вместе с ценами кэша. При подписке Claude Pro или Max токены отдельно не оплачиваются, тогда это эквивалент.

Специализированные модели-классификаторы (например, Jev от TypeSafe) рассматривались для задач «выбрать тип утверждения» и «оценить по признакам». Сейчас они в раннем доступе и требуют отдельного ключа, поэтому не подключены. Место для подключения — этап извлечения: классификация типа записи выполняется отдельным вызовом и легко заменяется.

## Сервисы и встроенные инструменты Claude Code

| Инструмент | Для чего |
|---|---|
| WebSearch | поиск открытых источников; оплата $10 за 1000 поисков при работе через API |
| WebFetch | чтение страниц, которые не отдаются напрямую; запасной путь для снимков |
| Read | PDF, изображения, кадры видео, файлы проекта |
| Bash | вызов `./strat` и скриптов анализа в `analysis/` |
| AskUserQuestion | вопросы руководителю с вариантами ответа |
| Список задач Claude Code | видимое продвижение по этапам |
| Субагенты (Agent) | `researcher`, `extractor`, `critic`, `respondent` |
| Навыки (Skills) | 15 процедур этапов |
| Хуки | SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, PostToolUseFailure, Stop |
| Строка статуса | проект, этап, источники, записи, вопросы к руководителю, стоимость |

## Собственные инструменты

| Инструмент | Для чего |
|---|---|
| `strat` (`tools/strat.py`, `./strat`) | CLI: проекты и этапы, источники и снимки, реестр утверждений, сверка цитат, проверки документов, анализ влияния, поиск, решения и обязательства, стоимость, отчёт, профиль данных, кадры видео, проверка персональных данных |
| MCP-сервер `strat` (`python3 tools/strat.py mcp`) | 21 инструмент для сред с MCP: Claude Code, Cursor, Codex, Windsurf |
| Тесты (`tests/test_strat.py`) | 16 сценариев: реестр, сверка цитат и чисел, проверки, хуки, MCP, стоимость, отчёт, параллельная запись состояния |

Только стандартная библиотека Python 3.9+. Ни внешних API, ни векторных баз, ни платных поисковиков.

## Необязательные утилиты

Агент работает без них, но с ними умеет больше:

| Утилита | Что даёт | Без неё |
|---|---|---|
| `pdftotext` (poppler) | текстовый снимок PDF и автоматическая сверка цитат из PDF | PDF читается через Read, цитаты помечаются как непроверенные |
| `ffmpeg` | кадры из видео для разбора интерфейсов | нужны скриншоты от руководителя |
| `whisper` | расшифровка аудиоинтервью на компьютере пользователя | нужна готовая расшифровка |
| `openpyxl` | более точное чтение xlsx (даты, форматы) | встроенный разбор xlsx |
| `pypdf` | запасной разбор PDF | см. `pdftotext` |

`./strat doctor` показывает, что из этого есть в среде.
