# Сценарий демонстрации (видео до 10 минут)

Задача видео — показать сквозной путь: запрос → работа агента → варианты → стратегия → продолжение после перерыва. Долгие ожидания вырезаются при монтаже, но в кадре должно быть видно, что агент делает.

## Подготовка

- Чистая копия репозитория, `./strat doctor` без ошибок.
- Claude Code запущен в папке, доверие к папке и MCP-сервер подтверждены заранее.
- Бриф демо-проекта от МегаФона в файле, материалы (если есть) лежат рядом.
- Включена запись экрана, крупный шрифт терминала, видна строка статуса.

## Раскадровка

| Время | Что показываем | Что сказать |
|---|---|---|
| 0:00–0:40 | README и структура папки | агент — это папка: правила, навыки, субагенты, хуки, инструмент `strat` |
| 0:40–1:40 | `/strateg <бриф>`, уточняющие вопросы с вариантами, ответы | агент спрашивает только то, что меняет следующий шаг; рамка записана в `brief.md` |
| 1:40–3:30 | план исследования, параллельные `researcher`, `./strat source list`, `./strat claim list` | у каждого факта источник, снимок и дословная цитата |
| 3:30–4:00 | попытка записать неверную цитату → отказ `strat` | выдумать цитату нельзя: она сверяется со снимком |
| 4:00–5:20 | `options.md`, вызов `critic`, попытка закрыть этап с ошибкой → отказ, исправление | разделение фактов и гипотез проверяется автоматически |
| 5:20–6:40 | выбор варианта руководителем, `product.md`, `comms.md` с аудитом обещаний, `validation.md` | обещания коммуникации привязаны к продукту |
| 6:40–7:00 | закрыть Claude Code посреди этапа | работа живёт в файлах |
| 7:00–8:00 | новый чат, «продолжи»: сводка от хука, продолжение с того же шага | выполненные шаги не повторяются |
| 8:00–9:00 | `report.html`: метки типов, приложения, «Как получен результат», `./strat cost` | видно, на чём основан каждый вывод и сколько стоил результат |
| 9:00–10:00 | `./strat decision add`, новые данные → `./strat impact` → обновление, `./strat decision check` | агент не бросает руководителя после решения |

## Что записать для описания работы

Во время прогона фиксируйте время начала и конца этапов (они есть в `state.json` и в отчёте), число вмешательств человека и ошибки агента, которые пришлось исправлять. Это нужно для раздела «Время, расходы, ошибки и помощь человека».

Скриншоты для описания: строка статуса; ответ `strat` на неверную цитату; отказ закрытия этапа; `report.html` (начало, приложение А и приложение В); `./strat cost`; сводка при старте новой сессии; `./strat impact`.
