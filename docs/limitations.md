# Ограничения

Что агент не умеет или умеет с оговорками. Лучше знать заранее, чем узнать на демонстрации.

## Источники

- Страницы, которые отрисовываются скриптами, `source fetch` скачивает почти пустыми. Тогда агент читает их через WebFetch и регистрирует как `source note` с пометкой «дословность не гарантирована»; цитаты из таких источников проверяются слабее.
- Сайты за входом, платные базы и корпоративные системы недоступны намеренно.
- Сверка цитаты доказывает, что текст есть в снимке источника, но не доказывает, что агент правильно его понял. Смысл проверяют `critic` и человек.
- PDF-сканы без текстового слоя читаются глазами модели через Read, автоматическая сверка цитат для них невозможна.

## Проверки

- `./strat lint` проверяет структуру и ссылки: есть ли раздел, ссылается ли пункт на запись нужного типа. Он не понимает смысл фразы. Если агент поставит правильную ссылку к неверному утверждению, проверка этого не заметит.
- Поиск персональных данных работает по шаблонам (телефоны, почта, номера документов, номера карт). Имена и адреса нужно убирать вручную.
- Поиск по базе знаний лексический (BM25 со стеммингом). «Смысловой» поиск достигается тем, что модель пробует несколько формулировок; векторного поиска нет.

## Модельные респонденты

Синтетические ответы правдоподобны, но не правдивы: у модели нет реального опыта, ответы тяготеют к усреднённым и вежливым, повторяют стереотипы. Агент использует их только для гипотез и проверки гайда, и проверка документов не пускает их в факты.

## Медиа

- Видео разбирается по кадрам; звук — только через расшифровку. Для расшифровки на компьютере пользователя нужен установленный whisper.
- Изображения анализирует модель; наблюдение привязывается к экрану и области, но точных координат нет.

## Стоимость

- Подсчёт опирается на формат журнала сессий Claude Code. Если формат изменится, `./strat cost` покажет нули; оценка Claude Code из строки статуса остаётся для сверки.
- При подписке Pro или Max цифры — эквивалент по тарифам API, а не реальные списания.

## Среды

- Полная автоматика (сводка при старте, запреты, журнал, стоимость, проверка перед концом хода) есть в Claude Code. В Cursor и других средах это записано в правилах как обязательные шаги, и их выполнение зависит от модели.
- Блокировки рассчитаны на одного пользователя на одном компьютере. Для совместной работы проект синхронизируется через git, одновременная правка одного проекта двумя людьми не поддерживается.
- Морфология и стоп-слова настроены под русский и английский.

## Сравнение с исходным способом

Протокол, задачи и рубрика готовы (`evals/`), но цифры в `evals/results.md` появятся только после реальных прогонов.
